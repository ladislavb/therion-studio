# Therion Studio 2026.6.8

Special thanks to Martin Sluka, Axel Hack, @CaverBruce, Stacho Mudrák, Martin Budaj, @apgeo, @vpicaver, and everyone else who tested the application, reported bugs, and shared valuable feedback. Your contributions have significantly improved the stability and usability of this and previous releases.

## Highlights

- Added SVG background support in the map editor alongside raster and XVI backgrounds, with placement, layer controls, and mixed-background workflows in one `.th2` file.
- Preserved manually collapsed scraps in the map Objects inspector across refreshes and text navigation, while still expanding the containing scrap when a map object inside it is selected.
- Added a persisted `Auto-collapse/expand Scraps` toggle to the map Objects inspector for users who prefer the inspector to keep only the selected object's scrap expanded.
- Remember recent pending point, line, and area type/subtype choices as quick drawing defaults while the map editor stays open.
- Auto-advance pending `point station` names while drawing repeated station points.
- Added single-key map drawing shortcuts for point/line/area tools, selected line reverse/close, and selected or next line-point smooth/control-handle toggles.
- Added `Ctrl` + left-drag canvas panning in the map editor while keeping Space-drag and right-drag panning.
- Improved tablet/stylus input handling in the map editor viewport and preserved more freehand line detail during freehand drawing.
- Blocked map-editor drawing inside unclosed scraps/line/area blocks and surfaced validation problems instead of letting editing enter an inconsistent state.
- Added validator automatic fixes for unclosed map blocks and empty line/scrap blocks, including navigation refresh after applying a fix.
- Added Windows backslash path handling improvements for Therion `input` path validation and completion workflows.
- Added `Esc` support for closing the find/replace panel from either the panel or editor focus.
- Improved therion binary detection.
- Fixed loaded raster/XVI background layers in the map editor so viewport-only actions no longer refresh the background layer model, preventing Objects inspector blinking and avoiding interruption of line vertex/control-handle interaction.
- Fixed raster/XVI background placement controls so pivot coordinates are interpreted in background/layer coordinates instead of canvas coordinates.
- Stabilized map line/area vertex and Bezier control-handle selection/dragging when `.th` or `thconfig` tabs are open beside a `.th2` map, including projects created from the default template.
- Kept inactive `.th` and `thconfig` tabs from driving map-object cursor synchronization, so validator/sidebar refresh work no longer steals map editor interaction state.
- Fixed raw editor path completion so accepting a path suggestion replaces the current path token instead of inserting the suggestion before it.
- Fixed Block editor canvas selection refresh and command reordering so simple command inspectors no longer blink and drag/drop operations complete reliably.
- Kept the committed line or area selected when `Esc` finishes drawing, and moved the Raw editor cursor to that inserted object.
- Preserved line selection when editing the selected line type/subtype from the Selection inspector.
- Fixed 3D viewer `Esc` handling so measure mode exits before and after selecting the first measurement point.
- Stabilized 3D viewer keyboard rotation and tilt shortcuts, including top/side view behavior, and made left/right rotation use a 5° step.
- Kept 3D viewer compass orientation stable when switching between top and side views.
- Fixed Windows installer Qt Quick deployment so the 3D viewer inspector QML imports are installed at the runtime `qml/` root used by Qt.
- Added opt-in diagnostic Qt/QML logging with `THERION_STUDIO_ENABLE_LOG=1` and optional `THERION_STUDIO_LOG_FILE` override for debugging GUI builds.

# Therion Studio 2026.6.9

This maintenance release focuses on map-editor input reliability and responsiveness based on Windows tester feedback after `2026.6.8`.

## Highlights

- Improved freehand line drawing responsiveness by sampling every accepted pointer position while throttling expensive preview redraws to roughly one frame.
- Reduced pointer-release stalls after drawing by applying freehand source insertions through delta text edits and deferring map-scene refresh work out of the release event.
- Bounded map-editor undo history to the most recent 200 source-edit steps per map tab so long editing sessions do not accumulate unbounded full-source snapshots.
- Tightened Windows tablet/stylus handling so duplicate synthetic mouse press suppression no longer blocks active mouse move or release completion paths.
- Narrowed map path hit-testing so clicks in visibly empty map space no longer select oversized path, line, decoration, or connector scene shapes; vertex and control-handle affordances remain larger for direct manipulation.
- Reduced path-selection latency in large map scenes by evaluating distance-ranked path candidates only near the click point instead of scanning the whole scene.
- Preserved area-fill selection near referenced border lines after the narrower path hit-testing change.
- Made map viewport fallthrough presses explicitly ignored so vertex and Bezier control-handle drags can be handled reliably by the scene items.
- Extended opt-in map-input diagnostics under `THERION_STUDIO_ENABLE_LOG=1` with hit-test, pointer-event, source-transaction, undo-stack, and snapshot-size details for future Windows input investigations.
